# Windows에서 직접 시험하기

이 설치는 선생님 컴퓨터에 PHP·MySQL을 함께 실행합니다. 클라우드의 실제 고객 자료는 포함하지 않는 빈 시험용 DB이며, 실제 운영 사이트에도 연결하지 않습니다.

## 1. 한 번만 준비하기

1. [Docker Desktop 공식 설치 안내](https://docs.docker.com/desktop/setup/install/windows-install/)에서 Windows용 Docker Desktop을 설치합니다. 보통 Intel/AMD 컴퓨터는 x86_64 버전입니다.
2. 설치 중 WSL 2 사용을 권하면 선택하고, 설치 후 재부팅합니다. `wsl --update` 등이 필요하다는 메시지가 나오면 오류 문구를 알려 주세요. BIOS 설정은 메시지를 확인한 뒤 안내합니다.
3. Docker Desktop을 열고 엔진 실행이 완료될 때까지 기다립니다. 처음 다운로드와 설치에는 인터넷과 여유 디스크 공간이 필요합니다.

## 2. 앱 실행하기

1. 제공한 `kimchibang-windows-test.zip`을 다운로드합니다.
2. 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다. 예: `C:\kimchibang-test`. 압축파일 안에서 바로 실행하지 마세요.
3. 폴더 안의 `windows-start.cmd`를 두 번 클릭합니다. 처음에는 PHP·MySQL 이미지를 준비하므로 몇 분 걸릴 수 있습니다.
4. 완료되면 브라우저와 메모장이 열립니다. 이때 **선생님 컴퓨터에서** `http://localhost:8080`으로 접속합니다. 클라우드 내부 주소를 여는 것이 아닙니다.
5. 아이디는 `admin`, 비밀번호는 열린 메모장의 내용을 복사해서 입력합니다. 비밀번호는 이 컴퓨터의 `.local\admin-password.txt`에 보관됩니다. 채팅에 보내지 마세요.

실행 파일은 PowerShell 실행 정책을 해당 실행 프로세스에서만 지정하며 시스템 설정을 변경하지 않습니다. 브라우저가 자동으로 열리지 않으면 위 주소를 직접 입력합니다. 8080 포트를 이미 쓰는 프로그램이 있으면 오류 문구를 알려 주세요. 처음 화면에 고객·주문이 없는 것이 정상입니다.

다음부터는 Docker Desktop이 실행된 상태에서 `windows-start.cmd`를 누르면 됩니다. 기존 계정·자료를 유지합니다. 종료는 `windows-stop.cmd`이며, 폴더의 `.env`나 `.local`을 지우면 안 됩니다.

## 3. 10분 실습

1. **고객 찾기 → 고객 등록**: 이름 `테스트 고객`, 닉네임 `연습용`, 주소 `123 Test Street`, 주로 입금하는 분 `TEST PAYER`로 등록합니다.
2. **새 주문 넣기**: 테스트 고객을 선택하고 포기김치 5kg 1개 + 깍두기 1개를 담습니다. 주문 합계는 $80, 배달비는 $0인지 확인합니다. 날짜는 오늘로 선택합니다.
3. **선택 수량 전달 완료**: 포기김치만 1개 전달합니다. 이번 전달분 받을 금액이 $50인지 확인합니다.
4. **입금 기록하기**: $50, eTransfer, 이번 입금자 `TEST PAYER`를 기록합니다. 깍두기 $30은 남아 있어야 합니다.
5. 깍두기를 전달하고 $30을 추가 입금합니다. 이번 입금자는 `ANOTHER TEST PAYER`로 입력해 두 이름이 각각 남는지 확인합니다. 완납 후 수정·취소가 막히는 것이 정상입니다.
6. **판매 통계**에서 오늘이 속한 월을 선택합니다. 김치 판매액 $80, 주문 1건을 확인합니다.
7. 새 배달 주문에 포기김치 5kg만 담아 $50 + 배달비 $5 = $55인지 확인합니다. 저장했다면 아직 전달·입금하기 전에 사유를 적어 전체 취소하는 연습도 할 수 있습니다.

잘 된 부분은 ‘정상’, 불편한 부분은 ‘어느 화면에서 무엇을 눌렀는지, 기대한 결과, 실제 결과’를 적어 보내 주세요. 오류 화면은 비밀번호나 실제 고객 정보를 가리고 전달하세요.

## 현재 한계

Windows 실행 도구는 제공했지만 이 클라우드에서 실제 Windows 설치를 직접 실행하지는 못했습니다. PHP·MySQL 업무 기능과 브라우저는 클라우드에서 검증합니다. Windows 환경별 설치 오류는 발생한 문구를 보고 함께 해결합니다. 통계는 주문 날짜 기준이며, 생산 배합·재료 계산 및 운영 서버 배포는 아직 다음 단계입니다.
