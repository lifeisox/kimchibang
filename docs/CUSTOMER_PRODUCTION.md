# 고객 기본값과 생산·재료 계산

## 고객 정보

고객 등록·수정에서는 이름만 필수입니다. 고객 종류·지역·기본 받는 방법도 선택하지 않아도 저장합니다. 지역은 Barrhaven, Kanata, Stittsville, Nepean, Carlington, Downtown, Vanier, Findlay, East, Etc를 제공합니다. 기존 엑셀에 다른 지역명이 있으면 그 값을 유지해 함께 표시합니다.

기본 받는 방법은 집으로 배달 / 직접 픽업 / 교회 중 선택합니다. 기본값이 없으면 새 주문 화면은 기존처럼 집으로 배달로 시작하며 변경할 수 있습니다. 주문을 만들 때만 복사하므로 고객 정보를 바꿔도 기존 주문의 수령 방식·메모·주소는 바뀌지 않습니다.

고객 선택 시 기본 받는 방법과 고객 메모를 주문에 복사합니다. 고객 원장의 ‘이 고객 주문 넣기’와 새 주문 화면 검색 모두 같습니다. 선택 후 사용자가 수정할 수 있고, 저장 오류로 돌아온 화면에서는 입력한 값을 유지합니다. 다른 고객을 명시적으로 다시 선택하면 새 고객의 기본값으로 채웁니다.

교회 수령은 픽업과 동일하게 배달비 $0입니다. 집으로 배달일 때만 할인 전 제품 합계 $80 미만이면 $5를 부과합니다. 전달 입력의 기본 수량은 주문 원래 수량이 아니라 **취소·이전 전달을 제외한 남은 전체 수량**입니다. 일부만 전달한 경우 미전달 제품을 0으로 바꾼 뒤 저장합니다.

## 생산 화면

왼쪽 **생산·재료 계산**에서 전달 예정일 범위를 지정하고 주문을 체크합니다. 최대 200건씩 표시합니다. 소매점 납품 물량은 선택 사항으로 추가할 수 있으며 포장 개수 대신 완성 중량 kg을 입력합니다. ‘재료 소요량 계산’은 고객·주문·입금·생산 완료 상태를 변경하지 않습니다. 이미 전달한 수량과 취소 수량을 빼고 계산합니다. 아직 생산 완료 기록은 없으므로 미전달이 곧 미생산을 의미하지는 않습니다. 어떤 주문을 생산할지 사람이 체크해 선택합니다.

제품별 배추·무 값은 엑셀 ‘소요량’ 시트의 배합값과 공유 수식을 해석한 `config/production-recipes.php`를 사용합니다. 구매 전 참고 계산이며 현재 재고 차감·소금·양념·발주 확정은 포함하지 않습니다. 현재 판매 용량은 제품 주문에 보존된 용량을 사용합니다. 동치미의 과거 엑셀 3kg 대신 현재 판매 3.2kg을 적용합니다.

총각·파·갓·열무·물김치 순한맛 등 확인되지 않은 배합은 ‘기준 확인 필요’로 표시합니다. 동치미·깍두기의 배추처럼 빈 재료 칸도 0으로 추정하지 않습니다. 합계는 계산 가능한 값만 모으며 미확인 항목이 있으면 전체 구매량이 아니라는 경고를 표시합니다. 개인용과 소매점용 기준은 서로 다를 수 있어 따로 계산합니다. 겉절이의 배추 보정은 개인 1.1배, 소매점 1.17배이며 깍두기 무는 개인용 G9의 1000/950 보정을 반영합니다.

## 추가 비용 없는 주소·배달 경로

현재 고객 주소 입력에는 **기존 등록 주소 재사용 제안**만 있습니다. 유료 API, 외부 주소 전송, 오타와 전체 주소 검색·주소 정확성 검증은 사용하지 않습니다.

오타와 전체 주소 자동완성은 정기 갱신되는 주소 데이터와 이용 조건을 확인해야 합니다. 공개 지오코딩 서비스도 무제한 무료 자동완성을 허용한다고 가정할 수 없습니다. 외부 서비스를 무료로 연결하면 무조건 비용이 없다고 안내하지 않습니다.

실제 도로·시간을 고려한 최적 배달 경로는 출발지, 도착지 좌표, 도로 이동 거리·시간 정보가 필요합니다. 이번 버전에는 넣지 않았습니다. 추가 비용 없는 첫 단계로 배달일별 주소 목록·방문 순서 수동 정리·지도 열기 링크를 고려할 수 있습니다. 도로 기준 최적화를 보장하는 기능은 별도 검토 대상입니다. 실제 집 주소를 소스 코드나 GitHub에 넣지 않습니다.

## 이미 실행 중인 Codespaces 업데이트

현재 실행 중인 Codespace에는 GitHub의 변경이 자동 반영되지 않습니다. Codespace를 삭제하거나 DB를 다시 만들지 마세요. 다음 명령은 클라우드 컨테이너에 Git이 없을 때만 설치하고 현재 개발 브랜치를 fast-forward로 갱신한 뒤, DB 백업과 스키마 업데이트를 실행합니다. 로컬 소스 변경이 충돌하면 강제로 덮어쓰지 않고 중단합니다.

```sh
cd /app
(command -v git >/dev/null || (apt-get update && apt-get install -y git)) && git -c safe.directory=/app pull --ff-only origin codex/cloud-preview && php scripts/apply-cloud-update.php
```

오류가 나면 출력 내용을 알려 주세요. 토큰·비밀번호를 직접 입력하거나 공유하지 않습니다. 성공 후 앱 탭에서 Ctrl+F5로 새로고침합니다. 기존 고객·주문 건수와 가격을 유지하며 백업은 `.local/import-backups/`에 비공개로 남습니다. Codespaces의 기존 사용자 데이터와 코드 변경이 있으면 삭제·리셋하는 명령을 쓰지 않습니다.
