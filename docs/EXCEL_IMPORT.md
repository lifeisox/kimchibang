# 확인한 엑셀 실제 가져오기

사용자가 코드나 SQL을 작성할 필요는 없습니다. 앱의 **엑셀 미리보기 → 실제 가져오기 → 저장할 내용 확인하기** 순서로 엽니다. 준비만 하면 실제 고객·주문은 바뀌지 않습니다.

최초 첨부 자료의 확인된 기준:

|항목|대상 / 금액 CAD|
|---|---:|
|고객|193명|
|주문|946건|
|제외|2건 (25 시트 281·323행)|
|김치 매출|$77,350|
|배달비|$235|
|기타 판매 (김밥)|$180|
|고객 동의로 받은 추가 수입|$82|
|전체 원본 금액|$77,847|

저장할 내용을 확인하고 ‘고객·주문을 실제로 저장합니다’ 확인란을 선택한 후 **백업 후 실제 가져오기**를 누르면 실제 저장합니다. 자료가 바뀌거나 준비 후 1시간이 지나면 다시 준비합니다. 준비 화면은 준비한 사용자만 실행할 수 있습니다.

개인 고객은 이름·닉네임·소속으로, 단체는 단체명·담당자로 구분합니다. 담당자와 소속도 고객 검색 대상입니다. 대사관 개인 고객과 대사관 단체 주문을 자동 합치지 않습니다.

과거 주문의 단가와 용량을 보존합니다. 무게를 모르는 제품은 용량 미확인으로, 현재 판매하지 않는 과거 제품은 비활성 보존용 제품으로 남깁니다. 기타 판매의 수량과 단가는 원본에 없으므로 추정하지 않고 원본 스냅샷에서 미확인으로 보존합니다. 추가 수입은 김치 매출 및 고객 예치금과 분리합니다.

엑셀의 생산·배송·입금 체크는 보존하지만 실제 배송일·입금일·입금 방법·수령 방식은 만들어 넣지 않습니다. 과거 주문은 조회 전용이며 주문 상세에서 원본 시트와 행을 확인할 수 있습니다. 향후 과거 자료 정정은 감사 기록을 갖춘 별도 기능으로 구현해야 합니다. 새로운 주문에는 기존 부분 배송·부분 입금 기능을 사용합니다.

같은 원본의 같은 행은 중복 등록하지 않습니다. 이미 가져온 행의 내용이 달라지면 덮어쓰지 않고 중단합니다. 다른 엑셀 파일의 고객을 이름만으로 자동 병합하지 않습니다. 보류·제외 행도 원본과 사유를 가져오기 이력에 보존합니다. 보류 해제 후 같은 원본을 다시 준비하면 새 대상만 추가할 수 있습니다.

## 개발자용 백업과 복원

실행 전 전체 DB SQL 백업은 웹 루트 밖 `.local/import-backups/`에 권한 0600으로 보관합니다. 실행 기록에는 파일명과 SHA-256을 저장합니다. 고객·주문·제품 쓰기는 DB별 잠금으로 가져오기와 직렬화합니다. 실행 오류는 업무 자료와 가져오기 이력을 한 트랜잭션으로 롤백하며 백업은 남습니다. 앱 외부에서 직접 DB를 수정하는 작업은 가져오기 중 중지해야 합니다.

복원은 현재 DB 전체를 되돌리는 관리 작업입니다. 사용자 화면에서는 제공하지 않습니다. 사용자의 명시적 복원 요청 후, 현재 DB와 일치하는 백업인지 확인하고 실행합니다. 도구는 복원 직전의 안전 백업도 생성합니다.

```sh
docker compose exec -T web php scripts/restore-import.php before-import-YYYYMMDD-HHMMSS-파일식별자.sql RESTORE_CURRENT_DATABASE
```

SQL 복원은 DDL 특성상 트랜잭션으로 되돌릴 수 없으므로 유지보수 중 실행합니다. 테스트는 별도 DB에서 전체 원본 가져오기·금액 대조·중복 방지·오류 롤백·백업 복원을 확인합니다. 운영 배포나 실제 개발 DB 가져오기는 자동 실행하지 않습니다.


## 현재 개발 데이터와 최신 엑셀

최초 확인한 고객 193명·주문 946건을 개발용 DB에 가져왔습니다. 총액 $77,847과 백업 파일 해시를 대조했습니다. 신규 엑셀 미리보기는 가능하지만 파일 내용이 바뀌면 다른 원본으로 판별하므로 현재 기능만으로 증분 이전을 실행하면 안 됩니다. 고객 중복 감지로 중단될 수 있으며, 무조건 새 원본으로 넣으면 중복 위험이 있습니다. 최신 파일 비교·증분 가져오기는 사용자 요청으로 개발하지 않습니다. 소량의 추가 내용은 고객 등록·새 주문 화면으로 입력합니다.

고객과 입금 내역에 입금자 성명 전용 필드를 추가했습니다. 과거 엑셀의 비고·닉네임에 들어 있는 이름은 입금자 여부가 불분명하므로 자동 추출하지 않습니다. 과거 입금은 성명 미기록을 유지하고, 고객의 기본 입금자만 수동 등록할 수 있습니다.

입금 완료 체크를 반영한 실제 입금 기록 합계는 $77,747이며, 전체 원본 기준 금액 $77,847과의 차이 $100은 미입금 2건입니다. 추가 수입 $82는 실제 입금액 안에서 별도 구분합니다. 전체 기준 금액을 전부 입금된 금액으로 처리하지 않습니다.
