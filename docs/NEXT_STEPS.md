# 다음 진행 안내

개발·테스트는 클라우드에서 하고 완성 후 Hostinger로 옮깁니다. Windows 로컬 설치는 필요 없습니다. 코드 저장·테스트·미리보기 설정은 개발자가 진행하고 계정 연결·새 비용·실제 운영 전환에 필요한 결정만 안내합니다.

## 지금 할 일

1. [업데이트 안내](CUSTOMER_SETTINGS.md)의 명령을 Codespaces 터미널에서 실행하고 앱을 Ctrl+F5로 새로고침합니다.
2. 원본 로고는 앱의 `/?page=brand`에서 PNG를 선택해 적용합니다. 채팅 인라인 이미지는 현재 도구에서 원본 파일로 전달되지 않으므로 앱에서 직접 선택합니다.
3. 고객 기본값 개인·집으로 배달, 고객 원장의 새 주문 선택, 통계 필터의 한 행 정렬과 3개 수입 분류를 확인합니다.
4. 새 주문을 배송 전에 일부 또는 전액 입금하고, 그 후 전달 완료를 기록해 두 상태가 독립적인지 확인합니다. 이미 입금이 배정된 제품 수량은 취소하지 못하는 것이 정상입니다.
5. 엑셀 이전이 필요하면 [승인한 분류](EXCEL_IMPORT.md)로 파일을 분석하고 실제 저장합니다. 개발 중에는 완료 후에도 메뉴가 유지됩니다. 실제 가져오기는 기존 업무자료를 백업 후 삭제하고 선택한 엑셀로 교체합니다. 계정·로고·제품·가격 설정은 유지합니다.

## 현재 범위

고객·제품 관리, 주문 등록·검색·수정·취소, 부분 전달, 배송 전후 입금·분할 입금, 입금자 성명, 고객 원장과 주간·월간·연간 통계·전년도 비교, 엑셀 실제 가져오기를 제공합니다. 생산·재료 계산과 최신 엑셀 증분 비교는 사용자 요청으로 제거·중단했습니다. 주소 제안은 기존 고객 주소를 재사용하는 기능이며 오타와 전체 주소 자동완성·최적 배달 경로·환불과 입금 정정은 아직 없습니다. 유료 API는 사용하지 않습니다.

## 운영 전환

개발용 Codespaces는 운영 서버가 아니며 실제 신규 비용·계정 연결·Hostinger 전환 전에 구체적인 준비 결과를 안내합니다. DB와 원본 로고를 함께 백업하고 별도 환경에서 복원을 검증합니다. 최종 운영에서만 `APP_HIDE_IMPORT_AFTER_COMPLETE=1`을 켜 가져오기 완료 후 메뉴를 숨깁니다. 현재 개발 환경에는 이 옵션을 켜지 않습니다. 비밀번호나 토큰은 채팅에 보내지 않습니다.


계정은 오른쪽 위 `아이디 님 · 계정`에서 두 번째 사용자를 추가합니다. 두 분이 같은 아이디를 공유할 필요가 없습니다. 셀폰 크기 확인은 F12 → Ctrl+Shift+M → 390×844로 실행합니다. 실제 엑셀 초기화는 파일을 다시 분석하고 삭제 범위·새 건수를 확인한 후에만 실행합니다.
